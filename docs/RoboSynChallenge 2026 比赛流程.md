# RoboSynChallenge 2026 比赛流程

> 更新时间：2026年7月31日  
> 核心赛制：所有队伍先参加统一的仿真初赛，晋级后再由主办方进行真机决赛。参赛者不需要自备机器人，也不需要亲自操作决赛真机。

## 一、完整流程

### 1. 报名并申请参赛账号

参赛团队首先在赛事官网提交访问申请，填写邮箱、队员姓名、队名、所属单位和参赛用途。每队最多 5 人。

申请经主办方审核后，团队会通过邮件收到 access token。参赛者使用报名邮箱和 access token 登录赛事系统。

报名入口：<https://robosyn-bench.net/#/register>

### 2. 获取代码、数据和基线模型

报名后，参赛团队可以使用官方提供的：

- RoboSynChallenge 代码库和 EmbodiChain 仿真环境
- 10 项双臂操作任务
- 官方合成数据和少量真实机器人示范数据
- ACT、Diffusion Policy、PI0、PI0.5 等基线策略
- 数据生成、训练和策略部署教程

官方代码库：<https://github.com/EDEM-AI/RoboSynChallenge>

### 3. 在本地进行训练和仿真自测

训练阶段为 **2026年7月13日至10月11日**。

各团队在自己的计算设备上训练策略，并在官方仿真环境中反复测试。团队可以使用官方数据，也可以利用 EmbodiChain 生成更多仿真轨迹。

这一阶段的仿真结果主要用于开发和调试，不是最终比赛成绩。

### 4. 按统一接口封装并提交策略

正式提交前，团队需要按照官方部署接口封装策略，主要包括：

- `deploy_policy.py`：加载模型、处理观测、产生动作并执行推理
- `deploy_policy.yml`：配置 checkpoint、任务、设备和评测参数
- `eval.sh`：启动官方评测流程

在赛事评测页面提交的主要内容包括：

- 代码仓库 URL
- Hugging Face checkpoint URL
- 模型和实验说明
- 训练数据来源
- 运行方式及依赖说明

部署教程：<https://edem-ai.github.io/RoboSynChallenge/html/tutorials/policy/your_own_policy.html>

### 5. 官方统一进行仿真初赛

仿真初赛时间为 **2026年10月11日至10月18日**。

初赛不是由参赛者自行上报本地成绩，而是：

1. 参赛团队提交模型、代码和 checkpoint。
2. 主办方在统一的 RoboSynChallenge 仿真环境中运行所有参赛策略。
3. 所有策略采用相同任务、环境和评测指标。
4. 主办方根据正式评测结果确定晋级团队。
5. 2026年10月18日公布决赛入围名单。

初赛完全使用仿真环境，不使用真实机器人。

### 6. 晋级团队继续更新模型

模型更新阶段为 **2026年10月18日至11月15日**。

晋级团队可以继续训练、优化模型、修复部署问题，并在11月15日前提交最终策略版本。

### 7. 主办方进行真机决赛

真机决赛从 **2026年11月15日** 开始。

参赛者不需要到现场操作机器人。主办方会把晋级团队的最终策略部署到统一的双臂机器人平台，并在标准化的真实场景中运行。

这样可以避免不同团队使用不同机器人硬件造成的不公平。最终排名以主办方发布的真机评测结果为准。

### 8. 公布结果、颁奖和展示

获奖结果预计在2026年12月上旬公布。优胜团队将参加 NeurIPS 2026 期间的颁奖和成果展示。

## 二、评分方式

初赛和决赛均记录以下指标：

1. **任务成功率**：策略完成任务的比例，是主要排名指标。
2. **动作步数**：完成任务所需的控制步数，越少越好。
3. **推理时间**：模型生成动作所需的时间，越低越好。

排行榜首先按照任务成功率排序；成功率相同时，动作步数更少、推理时间更低的方案优先。

## 三、关键时间表

| 时间 | 阶段 | 参赛团队需要做什么 |
|---|---|---|
| 7月13日起 | 报名开放 | 申请账号和 access token |
| 7月13日—10月11日 | 训练阶段 | 下载数据、训练模型、在仿真中自测 |
| 10月11日—10月18日 | 仿真初赛 | 提交策略，由主办方统一进行仿真评测 |
| 10月18日 | 晋级公布 | 查看决赛入围名单 |
| 10月18日—11月15日 | 决赛更新 | 晋级团队继续优化并提交最终模型 |
| 11月15日起 | 真机决赛 | 主办方统一部署和运行真实机器人评测 |
| 12月上旬 | 颁奖展示 | 公布结果并在 NeurIPS 2026 展示成果 |

## 四、一句话流程

**报名获取账号 → 下载代码和数据 → 本地训练及仿真自测 → 提交模型和代码 → 主办方统一仿真初赛 → 晋级团队更新模型 → 主办方统一真机决赛 → 公布排名和颁奖。**

## 五、注意事项

- 截至2026年7月31日，比赛处于报名和训练阶段。
- 官网尚未公开说明晋级队伍数量、每天允许提交的次数以及截止时间的具体时区。
- 10月11日是初赛评测开始日期，建议提前完成初赛版本提交，不要等到当天。
- 最新细则应以赛事官网和主办方邮件通知为准。

赛事官网：<https://robosyn-bench.net/>
