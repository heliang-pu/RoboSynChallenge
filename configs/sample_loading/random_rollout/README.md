# random_rollout

sim-RECAP rollout 采集专用设置,基于官方 `random` 协议,唯一差异:

- `random_cube_pose.position_range` 的 y 上界 0.0 → **-0.19**。
  依据实测几何:架子 27.5×11.6cm(scale 1.1),任意 yaw 下水平外沿
  距中心最大 14.9cm;架子中心 y ≥ 0,故试管中心 y ≤ -(0.149 + 试管
  半径 0.008 + 余量 0.03) ≈ -0.19,保证试管不会出生在贴着/压着架子的
  位置(官方范围最坏情况下两者直接接触,episode 无法完成,只产生
  无信息量的失败样本)。

正式评测请仍用官方 `random` 设置,本目录只用于数据采集。
